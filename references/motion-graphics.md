# Motion graphics: hacer visible una idea

## Cuándo consultar

Para diseñar o corregir gráficos en movimiento que expliquen, comparen, construyan identidad o cuenten una historia. La animación es el campo amplio; aquí se priorizan formas, tipografía, diagramas, datos y objetos con comportamiento. No exige actuación compleja de personajes ni 3D. Para guion y bocetos consulta [guion/storyboard](guion-storyboard.md); para persistencia y cámara, [continuidad](continuidad-escenas.md); para corregir resultados débiles, [antipatrones](antipatrones-motion.md).

## 1. Elegir qué transforma el movimiento

Una entrada presenta un objeto; un comportamiento muestra cómo responde; una transformación cambia una relación; una secuencia conectada permite inferir una historia. Ninguno es automáticamente superior: el encargo determina qué necesita la pieza. Un identificador breve puede resolverse con un gesto; una explicación de funcionamiento necesita mostrar relaciones además de nombres.

En una pieza narrativa o explicativa, convierte el tema en una pregunta o promesa y el contenido en acciones. «Organizar gastos» puede volverse «¿qué cambia cuando se separa lo necesario de lo opcional?». Los importes conservan identidad mientras se agrupan; un límite se hace visible; una decisión modifica el saldo. No inventes cifras para hacer funcionar el ejemplo: usa datos autorizados o una representación cualitativa claramente conceptual.

Antes del acabado, describe los momentos principales con una ficha breve:

| Campo | Pregunta que resuelve |
|---|---|
| Promesa | ¿Qué entenderá o sentirá la audiencia al terminar? |
| Hilo visual | ¿Qué objeto, relación, palabra o transformación seguimos? |
| Estado anterior | ¿Qué debe reconocerse antes del cambio? |
| Acción y disparador | ¿Qué ocurre, qué lo provoca y cómo se ve? |
| Respuesta y consecuencia | ¿Qué cambia y qué permanece después? |
| Enlace | ¿Por qué conduce al siguiente momento? |
| Representación | ¿Es literal, esquema o metáfora? ¿Qué simplifica? |

No todos los relatos necesitan conflicto, héroe o una toma continua. Curiosidad, comparación y descubrimiento también sostienen una historia. Para piezas de identidad, la transformación puede ser emocional o gráfica; para tipografía cinética, las propias palabras pueden ejecutar la acción.

## 2. Atraer con una revelación que valga la pena

El inicio puede mostrar una fricción reconocible, un resultado inesperado o una relación incompleta. El movimiento permite descubrir cómo se resuelve. Diseña el cierre junto con esa promesa: la sorpresa debe conducir a comprensión y el resultado debe poder reconocerse.

Construye variedad por función: un plano general orienta; el detalle descubre; la comparación diferencia; el regreso al conjunto muestra una consecuencia. Alterna intensidad y pausa. Un cambio gráfico que no aporta información puede sostener atmósfera, pero no reemplaza el desarrollo. No hay una frecuencia universal de cortes ni una garantía de retención por añadir efectos.

Define una gramática de forma y movimiento: qué colores representan relaciones, qué materiales existen, cómo responde cada familia de objetos, qué hace la cámara y qué energía lleva el ambiente. La coherencia permite variar encuadres sin convertir cada momento en un estilo diferente. Contraste, silueta y proporción sostienen el atractivo antes del brillo.

## 3. Elegir recursos por su función

Este vocabulario sirve para decidir, no para marcar una cuota de técnicas. Escoge las que aclaren la idea; la quietud y un corte limpio siguen disponibles.

| Necesidad | Recursos posibles | Condición que conviene revisar |
|---|---|---|
| Conectar | Ruta dibujada, señal, nodos que responden | Origen, dirección, destino y consecuencia legibles; no inventar conexiones |
| Explicar estructura | Ensamblaje o vista explotada | Conservar orientación, escala, orden de piezas y referencia del conjunto |
| Cambiar de estado | Activación, llenado, agrupación o sustitución | Que antes y después se distingan y que el cambio tenga causa reconocible |
| Expresar parentesco | Morph, forma intermedia o máscara | Correspondencia semántica y geometría intermedia legible; un morph no prueba equivalencia |
| Descubrir un mecanismo | Apertura, oclusión o zoom semántico | El acercamiento revela información nueva y permite entender el regreso |
| Transferir atención | Seguimiento, recorrido o match cut | Conservar anclaje, identidad o dirección cuando esa continuidad importa |
| Mostrar reacción | Anticipación, contacto, respuesta, asentamiento | Separar el estímulo del resultado lo suficiente para percibirlos |
| Ordenar un grupo | Stagger por dependencia, posición o categoría | Que el orden signifique algo; no retrasar la comprensión por animar cada pieza |
| Comparar datos | Reordenar objetos existentes, crecer barras o mostrar diferencias | Mismas unidades y escala; distinguir animación de presentación de evolución real |
| Hacer actuar palabras | Separar, comprimir, unir, contradecir o completar | Significado y lectura sobreviven al movimiento; captions conservan su función |
| Construir ambiente | Capas, paralaje, partículas o textura | Menor energía que el foco; no sugerir evidencia física inexistente |
| Confirmar | Encaje, convergencia, cambio de símbolo o pausa | Resultado estable y tiempo para reconocerlo |

Para cifras, mapas y procesos técnicos, verifica las relaciones que se presentan como reales. Una línea luminosa puede ser una metáfora de transferencia sin ser un circuito eléctrico literal. Una barra que interpola entre dos valores no establece que existan mediciones intermedias. El estilo no resuelve la exactitud.

## 4. Objetos preparados para comportarse

Descompón la geometría por función: estructura, partes móviles, pivotes, contactos, oclusiones y estado. Una tapa gira desde su articulación; una tecla cambia recorrido y sombra; un objeto trasladado conserva lo que contiene. No es necesario añadir caras para expresar intención: trayectoria, pausa y respuesta pueden hacerlo.

Relaciona timing, espaciado, aceleración y asentamiento con masa y material aparentes. Un mecanismo rígido, papel y una burbuja no necesitan el mismo rebote. La exageración puede facilitar lectura móvil si conserva el significado y respeta la identidad. La física simulada es una opción; a veces una trayectoria diseñada resulta más clara y fácil de reconstruir.

Separa acción principal, respuesta secundaria y ambiente. Un mundo puede conservar actividad mientras el foco descansa. Evita tanto mantener todo a máxima energía como dejar un plano detenido esperando el próximo título.

## 5. Pasar de intención a producción

En una pieza nueva, integra esta especialidad en el flujo ya acordado; no agregues documentos por costumbre ni reinicies etapas para una corrección local.

1. **Promesa y guion de acciones.** Decide qué causa el cambio y qué aporta cada canal: imagen, palabras y sonido.
2. **Bocetos y estados clave.** Dibuja antes, cambio y resultado de los momentos difíciles; el style frame fija acabado, no fluidez.
3. **Animática y bloqueo.** Prueba duración, trayectoria, cámara, contacto y consecuencia con recursos simples. Si la explicación depende de una relación visual, comprueba que esa relación se reconoce antes de pulir.
4. **Acabado e integración.** Refina materialidad, curvas, detalles, transiciones, voz medida y sonido. El mapa sonoro puede comenzar en el guion; no hace falta esperar al final para descubrir una mala sincronía.
5. **Revisión del resultado.** Mira el movimiento continuo y el archivo codificado, además de cuadros representativos. Corrige la capa responsable del fallo.

En HyperFrames, Remotion o un motor local, la misma intención puede realizarse con estructuras diferentes. Conserva un único tiempo controlado y calcula el estado completo al buscar un instante. Consulta los contratos de la versión elegida; esta guía no es una API ni autoriza cambiar de motor.

## 6. Pruebas editoriales para una explicación visual

Usa las que resuelvan incertidumbres reales. No son una certificación ni requieren exportar varias versiones finales.

- **Sin títulos ni voz:** oculta temporalmente esas capas. ¿Se distingue la acción y su relación principal? No se exige comprender nombres, cifras o toda la explicación sin palabras. En una pieza deliberadamente tipográfica no elimines su contenido para juzgarla.
- **Verbo y consecuencia:** describe qué ocurre entre rótulos. Si solo puedes decir «aparece» y «desaparece», revisa el mecanismo o reconoce que el formato acordado es una presentación.
- **Persistencia:** sigue un objeto o relación a través de cambios de plano. Busca estados que se reinician sin motivo.
- **Cámara:** señala qué información descubre cada movimiento y si conserva orientación. Una cámara quieta puede cumplir mejor esa función.
- **Ritmo y lectura:** reproduce al tamaño y velocidad previstos. Comprueba el reconocimiento del inicio y la permanencia del resultado.
- **Sonido:** alinea el ataque audible con el acontecimiento; escucha si timbre, jerarquía y pausas ayudan. Las mediciones no prueban esa experiencia.

Registra hallazgos con tiempo, observación, efecto y corrección. Por ejemplo: «03,2 s: el objeto atraviesa la puerta antes de que se abra; se pierde causalidad; adelantar la apertura o retrasar el cruce». No sumes puntos para declarar profesional una obra.

## 7. Laboratorio opcional

[Una señal abre un paso](../assets/motion-causal/index.html) es una microhistoria autónoma de SVG y JavaScript. Permite inspeccionar estados con `seek(t)` en segundos, `renderFrame(f)` a 30 fps y ocultar rótulos con el control de la página. Cursor → pulsación → señal → apertura → cruce → consecuencia persistente. Es un mecanismo simbólico, no una simulación física. No incluye audio, voz ni adaptadores de framework y no sustituye las pruebas audiovisuales de una producción.

Úsalo para estudiar relaciones y reconstrucción temporal; no heredes su paleta, escenario ni duración para otros encargos. Si el usuario quiere aprender, una práctica A/B puede comparar una tarjeta «ABRIR» con la acción de abrir: pedir qué comunica cada una y señalar instantes concretos. No produzcas dos videos completos por defecto.
